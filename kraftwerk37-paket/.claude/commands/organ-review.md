# Organ Review

Du prüfst ob der aktuelle Code zur KRAFTWERK37-Philosophie passt.

## Deine Aufgabe

1. **Identifiziere das Organ** in dem gearbeitet wird:
   - BrandMatrix37 (Herz) → Identität, DNA, Archetypen
   - PageForge37 (Gesicht) → Präsenz, Website
   - FormCraft37 (Hände) → Formulare, Kontakt
   - FlowEngine37 (Nervensystem) → n8n Workflows
   - TrackPulse37 (Bewusstsein) → Analytics
   - CommsFlow37 (Lunge) → Email, Dialog
   - VoiceOut37 (Stimme) → Content, Social
   - MemoryVault37 (Gedächtnis) → Knowledge Base
   - Epiphyse37 (Zirbeldrüse) → KI-Intuition

2. **Prüfe die Philosophie-Konformität:**

   **WENIGER IST MEHR**
   - [ ] Jede Zeile verdient ihren Platz?
   - [ ] Keine Über-Engineering für "Flexibilität"?
   - [ ] Keine premature Optimization?

   **TRUST BUT VERIFY**
   - [ ] Logging das erzählt, nicht nur aufzeichnet?
   - [ ] Keine Black Boxes?
   - [ ] Entscheidungen nachvollziehbar?

   **GDPR BY DESIGN**
   - [ ] Keine Cloud LLM APIs ohne Erlaubnis?
   - [ ] Daten bleiben lokal wo möglich?
   - [ ] Datenminimierung beachtet?

3. **Prüfe Code-Konventionen:**
   - [ ] Deutsch für Business-Begriffe (Archetyp, BrandDNA)?
   - [ ] Englisch für technische Begriffe (EventBus, handleSubmit)?
   - [ ] Keine `any` Types ohne Kommentar?
   - [ ] Dateien unter 300 Zeilen?

4. **Prüfe Organ-spezifische Regeln:**
   - BrandMatrix37: Schema-Änderungen haben weitreichende Folgen - extra sorgfältig?
   - FlowEngine37: Workflows exportierbar und testbar?
   - Epiphyse37: Confidence Scores und Reasoning dabei?

## Output

Gib eine kurze, ehrliche Einschätzung:
- Was passt gut zur DNA?
- Was weicht ab?
- Konkrete Verbesserungsvorschläge (maximal 3)

**Kein Lob. Kein Smalltalk. Nur Substanz.**
